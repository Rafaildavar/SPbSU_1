# Инструкция по использованию

## Быстрый старт

### Запуск программы

```bash
python3 count_unique_ipv6.py input.txt output.txt
```

Где:
- `input.txt` — путь к входному файлу с IPv6 адресами
- `output.txt` — путь к выходному файлу с результатом (количество уникальных адресов)

### Пример из условия задачи

В проекте уже есть файл `input.txt` с примером из условия. Для запуска:

```bash
python3 count_unique_ipv6.py input.txt output.txt
cat output.txt
```

Ожидаемый результат: `4`

## Генерация тестовых данных

### Генерация примера из условия

```bash
python3 generate_test_data.py example
```

Создаст файл `input.txt` с 5 адресами из условия задачи.

### Генерация большого файла

```bash
python3 generate_test_data.py large_input.txt 1000000
```

Создаст файл `large_input.txt` с 1 миллионом случайных IPv6 адресов.

## Структура файлов

- `count_unique_ipv6.py` — основная программа для подсчета уникальных адресов
- `ipv6_normalizer.py` — модуль нормализации IPv6 адресов
- `generate_test_data.py` — генератор тестовых данных
- `README.md` — подробное описание проекта
- `АЛГОРИТМ.md` — описание алгоритма решения

## Требования

- Python 3.6 или выше
- Только стандартная библиотека Python (без внешних зависимостей)

## Примечания

- Программа выводит информацию о прогрессе в stderr
- Временные файлы создаются автоматически и удаляются после завершения
- Программа оптимизирована для работы с файлами до 10⁹ строк при ограниченной памяти (~1 ГБ)
