# Инструкция по загрузке в GitHub

## Подготовка репозитория

Все файлы готовы для загрузки. Структура проекта:

```
.
├── count_unique_ipv6.py    # Основная программа
├── ipv6_normalizer.py      # Модуль нормализации IPv6 адресов
├── generate_test_data.py   # Генератор тестовых данных
├── input.txt               # Пример входного файла
├── README.md               # Описание проекта
├── АЛГОРИТМ.md            # Описание алгоритма (для ответа)
├── ИНСТРУКЦИЯ.md          # Инструкция по использованию
├── .gitignore             # Исключения для Git
└── GITHUB_UPLOAD.md       # Эта инструкция
```

## Команды для загрузки в GitHub

Выполните следующие команды в терминале:

```bash
# Перейдите в директорию проекта
cd "/Users/remi/Desktop/GUAP/ИБ/Новая папка"

# Инициализируйте Git репозиторий (если еще не инициализирован)
git init

# Добавьте удаленный репозиторий
git remote add origin https://github.com/Rafaildavar/SPbSU_1.git

# Добавьте все файлы
git add .

# Создайте коммит
git commit -m "Решение задачи: Подсчет уникальных IPv6-адресов в большом файле"

# Загрузите в GitHub (main ветка)
git branch -M main
git push -u origin main
```

## Альтернативный способ через GitHub CLI

Если у вас установлен GitHub CLI:

```bash
cd "/Users/remi/Desktop/GUAP/ИБ/Новая папка"
gh repo create Rafaildavar/SPbSU_1 --public --source=. --remote=origin --push
```

После загрузки проверьте:
1. Все файлы отображаются в репозитории
2. README.md корректно отображается на главной странице
3. Код можно просмотреть и скачать
